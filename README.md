# Playwright\_Pytest\_HR\_Management\_Web\_Application



Automation Framework for https://opensource-demo.orangehrmlive.com



**📌 Project Overview**

This project focuses on automating the functional testing of the OrangeHRM Web Application using Playwright (Python).

The automation suite validates core modules such as:



* Login \& Authentication
* Menu Navigation
* User Management
* Leave Management
* Claim Management
* My Info Section
* Forgot Password Flow
* CICD Integration completed



The goal is to ensure that critical workflows behave as expected under both positive and negative scenarios.



**🎯 Project Objective**



1. To design and implement a robust automation framework that:
2. Simulates real user interactions
3. Validates key HRM functionalities
4. Ensures cross‑browser compatibility
5. Provides detailed logs, screenshots, and reports
6. Follows best coding practices and OOP principles



**📁 Project Structure**

**│**

**├── pages/                 # Page Object Model classes**

**├── locators/               # Locators stored for each pages**

**├── tests/                 # Test cases grouped by pages**

**├── test\_data/              # Test data stored in excel**

**├── utilities/             # Helpers (Excel helper, logger helper, screenshot helper)**

**├── screenshots/           # Captured screenshots**

**├── reports/               # HTML test reports**

**├── logs/                   # Test logs stored**

**├── conftest.py            # Fixtures (browser, page)**

**├── pytest.ini             # Pytest configuration**

**├── requirements/           # plugins details are added**

**├── Jenkinsfile/            # Integrated CICD**

**└── README.md              # Project documentation**
